# 0002 Zero Vector EGA Rendering

All interactive visual elements—including actors, inventory items, interactive objects, and door state overlays—must be rendered strictly using authentic 16-color EGA raster assets and 12-frame 4-way walk cycles. Canvas vector geometric primitives (`fillRect`, `strokeRect`, `arc`) are strictly prohibited for game objects, ensuring strict graphical fidelity to 1987 Lucasfilm adventure games.
